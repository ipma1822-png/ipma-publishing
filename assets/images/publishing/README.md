# IPMA Publishing production image slots

These paths are reserved for approved production images created in the separate image workflow.

- `hero-main.webp` — homepage main hero
- `digital-library.webp` — Digital Library section
- `martial-education.webp` — martial arts / education publishing
- `research-knowledge.webp` — research / knowledge publishing
- `global-publishing.webp` — global digital distribution
- `verification.webp` — ISBN / edition / verification
- `submissions.webp` — author / manuscript submissions

Do not replace existing public placeholders until the final image is approved and uploaded.
